# LGPD G2c-3 — Log de acesso a PII — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) ou superpowers:executing-plans. Steps usam checkbox (`- [ ]`).

**Goal:** Registrar (accountability) quem consulta/exporta/exclui dados de cliente final via as rotas do G2c-2, exibir o histórico numa tela read-only, e incluir esse log na retenção do G2c-1.

**Architecture:** Modelo `PiiAccessLog` + serviço registrar/listar; instrumentação **não-bloqueante** nas 3 rotas existentes; rota de listagem + seção na UI; extensão do expurgo. Tudo tenant-scoped.

**Tech Stack:** Prisma (migração à mão), Next.js route handlers, NextAuth (`getSession`), `getClientIp` de `@/lib/rate-limit`, Vitest.

## Global Constraints

- Instrumentação **não-bloqueante**: `void registrarAcessoPii({...}).catch(...)` — falha de log nunca quebra a operação nem altera a resposta.
- Tudo **tenant-scoped**; listagem e visualização só admin/MANAGER.
- Migração additiva à mão (timestamp > `20260624100000`); `prisma generate` p/ o client.
- `PiiAccessLog` entra no expurgo (12 meses) junto dos demais logs.
- Suíte verde; tsc/lint limpos.

```ts
import { prisma } from '@/lib/prisma'

export type AcessoPiiInput = {
  tenantId: string
  userId: string
  acao: 'CONSULTA' | 'EXPORTACAO' | 'EXCLUSAO'
  alvo: string
  detalhe?: string
  ip?: string | null
}

export async function registrarAcessoPii(p: AcessoPiiInput): Promise<void> {
  await prisma.piiAccessLog.create({
    data: {
      tenantId: p.tenantId,
      userId: p.userId,
      acao: p.acao,
      alvo: p.alvo,
      detalhe: p.detalhe,
      ip: p.ip ?? undefined,
    },
  })
}

export async function listarAcessosPii(tenantId: string, opts?: { limit?: number }): Promise<unknown[]> {
  return prisma.piiAccessLog.findMany({
    where: { tenantId },
    orderBy: { createdAt: 'desc' },
    take: opts?.limit ?? 100,
  })
}
```

Nota: o teste espera `ip: '1.2.3.4'` no `data` quando passado; como o serviço usa `p.ip ?? undefined`, com `ip:'1.2.3.4'` o `data.ip` é `'1.2.3.4'` (ok). (Se o teste falhar por `detalhe`/`ip` undefined em outro caso, é por causa do `?? undefined` — mas o teste do Step 1 passa ip e detalhe.)

```ts
import { NextResponse } from 'next/server'
import { getSession, unauthorizedResponse } from '@/lib/session'
import { listarAcessosPii } from '@/services/lgpd/pii-access-log.service'

function permitido(role?: string | null) {
  return role === 'SUPER_ADMIN' || role === 'ADMIN' || role === 'MANAGER'
}

export async function GET() {
  const session = await getSession()
  if (!session?.user?.tenantId) return unauthorizedResponse()
  if (!permitido(session.user.role)) return NextResponse.json({ error: 'Sem permissão' }, { status: 403 })
  const acessos = await listarAcessosPii(session.user.tenantId)
  return NextResponse.json(acessos)
}
```
